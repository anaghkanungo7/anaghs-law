# Original Formulation

The first versioned public formulation of **Anagh's Law**, coined by **Anagh Kanungo on 10 October 2026**.

**Clear the maximum, clear the rest.**

> If one object’s spatial envelope contains another’s, any placement that clears the containing envelope also clears the contained envelope, provided that placement is admissible for both.

This release includes the definition, bus–tunnel corollary, containment proof, limitations, machine-readable citation, and a three-page author-prepared note with editable source. It records the naming and formulation; the elementary mathematics is not new. The note has not been peer reviewed and has no DOI.
